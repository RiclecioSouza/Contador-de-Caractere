# Contador-de-Caractere
Aplicação web desenvolvida para analisar textos em tempo real, apresentando informações como quantidade de caracteres, palavras, frases e tempo estimado de leitura.

O projeto possui uma interface simples, permitindo acompanhar as estatísticas conforme o usuário digita ou cola um texto.

## 🚀 Funcionalidades
* **Contagem de caracteres:** calcula a quantidade total de caracteres presentes no texto.
* **Excluir espaços:** permite desconsiderar espaços em branco na contagem de caracteres.
* **Contagem de palavras:** identifica e contabiliza as palavras presentes no texto.
* **Contagem de frases:** identifica frases utilizando pontuações como ponto final, exclamação e interrogação.
* **Tempo de leitura:** estima o tempo necessário para ler o conteúdo, considerando uma média de 200 palavras por minuto.
* **Atualização em tempo real:** atualiza automaticamente as estatísticas conforme o conteúdo é modificado.

## 🛠️ Tecnologias utilizadas
* **HTML5:** estruturação dos elementos da aplicação.
* **CSS3:** estilização, responsividade e organização visual.
* **JavaScript:** implementação das funcionalidades e manipulação do DOM.

## 🎯 Objetivo do projeto
Este projeto foi desenvolvido com o objetivo de praticar e consolidar conhecimentos fundamentais de desenvolvimento Front-End, especialmente:

* Manipulação do DOM.
* Eventos JavaScript (`input` e `change`).
* Manipulação de strings.
* Expressões regulares.
* Operador ternário.
* Métodos de arrays.
* Operações matemáticas.
* Estilização responsiva com CSS Grid.
* Utilização de variáveis CSS.
